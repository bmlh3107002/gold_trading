# Kế hoạch theo giai đoạn

Mỗi giai đoạn một file `GD<n>-ke-hoach.md`: **thứ tự làm + checklist + prompt dán vào phiên chat mới**. Dùng để theo dõi tiến độ qua nhiều phiên chat.

- Trạng thái chi tiết từng mã việc/case vẫn nằm ở `docs/giai-doan/` (nguồn sự thật). Xong một bước → tick ở **cả hai** file.
- Prompt khởi động một lần cho mỗi giai đoạn (chốt quyết định) nằm ở `docs/prompts/`.
